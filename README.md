# Unity Dialogue System

A small Unity/C# project exploring the implementation of a reusable dialogue system for interactive games.

The project focuses on organizing dialogue data and controlling the flow of conversations between the player and game characters.

## Features

* Sequential dialogue
* Dialogue state management
* Character interaction
* Reusable dialogue components
* Configurable dialogue content

## Technologies

* Unity
* C#
  
## Purpose

This project was created as a focused experiment in implementing dialogue systems independently from other gameplay mechanics.

The goal was to explore how dialogue data and game logic can be separated to make the system easier to reuse across different interactions.

## Future Improvements

* Add branching dialogue choices

* Add dialogue events
